# Security Policy

These demos are examples for [Datalium Strata](https://github.com/datalium/strata). They aren't meant to be deployed as they are.

**Please don't report a security issue in a public issue, discussion or pull request.**

- **A vulnerability in Strata itself:** follow the [Strata security policy](https://github.com/datalium/strata/blob/main/SECURITY.md).
- **A vulnerability in these demos** (a demo that teaches an unsafe pattern, or a vulnerable dependency): [report it privately](https://github.com/datalium/strata-demos-rust/security/advisories/new) from this repository's Security tab, or email [security@datalium.com](mailto:security@datalium.com).

The response times in the Strata security policy apply to both.
